# Dhruv Pawar — Black Premium Portfolio

## Run
```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

## If the page is still blank
1. Make sure the terminal is inside this project folder.
2. Stop the old Vite server with `Ctrl + C`.
3. Delete `node_modules` and `package-lock.json` from this project.
4. Run `npm install`.
5. Run `npm run dev`.
6. If the page shows **Portfolio runtime error**, copy the error shown on the page and send it.

## Included stack
React, JavaScript, Redux, Tailwind CSS, Framer Motion, Vite, HTML5/CSS3 and Lucide React.

## Theme
Black / graphite / white minimalist theme with restrained emerald highlights. No blue primary accent.
